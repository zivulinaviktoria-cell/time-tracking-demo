1. Актуальность и сравнительный анализ

Современные компании переходят на гибридный формат, сотрудники используют множество устройств. Традиционные системы учёта не отвечают требованиям надёжности и мобильности. Обоснование выбора архитектуры выполнено через сравнение с существующими аналогами (таблица 1).

2. Архитектура и ключевые принципы

Система строится по клиент-серверной модели с принципом Local-first. Локальная база данных SQLite — источник истины. Сервер выполняет роль реплики для синхронизации.

  • Офлайн-работа: SQLite на каждом клиенте → полная работоспособность без интернета.
  • Надёжная синхронизация: очереди изменений, версионирование (sync_version), Last Write Wins.
  • Кроссплатформенность: Flutter (iOS/Android), React (web), Avalonia UI (RED OS/Windows).
  • Ролевая модель: Сотрудник / Руководитель / Администратор.

3. Результаты и дальнейшая работа

Разработана архитектура, обеспечивающая офлайн-работу и синхронизацию. Проведён сравнительный анализ, подтверждающий преимущества. Дальнейшие этапы: реализация серверной части на C# (.NET 8), разработка клиентских приложений, тестирование.

Заключение

Разработанная архитектура обеспечивает полноценную офлайн-работу (SQLite), надёжную синхронизацию через очереди и версионирование, а также полную совместимость с RED OS. Это закрывает рыночную нишу, в которой отсутствуют конкурентоспособные отечественные решения.
